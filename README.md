# VD-1

A lo-fi drum machine plugin built around a simulated DSP chip: swap the chips, load different
firmware. CLAP, macOS first.

**Website:** https://vdsp-audio.com

This repository holds the releases and the issue tracker. The source code is not public.

## Download

The first release is not out yet. When it is, it will be here:

| Platform | File |
|---|---|
| macOS (CLAP) | [`VD-1-macOS-CLAP.zip`](https://github.com/vdsp-audio/vd-1/releases/latest/download/VD-1-macOS-CLAP.zip) |

Install: unzip, move `VD-1.clap` into `~/Library/Audio/Plug-Ins/CLAP/`, rescan plugins in your
host. The plugin is signed and notarized by Apple, so macOS opens it without a warning.
