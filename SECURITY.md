# Security policy

If you find a security problem in VD-1, please **do not open a public issue**. Report it privately
through GitHub: open this repository's **Security** tab and click **Report a vulnerability**
([how it works](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)).

Please include what you found, how to reproduce it, and the VD-1 version. We aim to answer within
a week, and to credit you in the release notes of the fix unless you ask us not to.
